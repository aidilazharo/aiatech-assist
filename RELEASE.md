# ATGV AIATECH Assist v0.0.64

Release date: 2026-11-23

## Nonblocking access and role-based connection permissions

- Allow manual Next from technology-stack and credential setup without a successful remote connection test; verification status is not fabricated.
- Open selected projects with local functionality when Jira/Confluence validation is unavailable, retaining server-side checks for actual remote operations.
- Add **Skip · Enter ATGV** on the project search/selection screen; explicitly create or reopen a local ATGV workspace without choosing an unrelated project.
- Display a persistent, non-dismissible connection reminder below the main top bar with **Recheck** and right-aligned **Settings** buttons.
- Verify Jira Browse Projects/Create Issues and Confluence space read/Create Page for every active role; verify GitHub repository read for every role, and GitHub write for Developer/software-developer.
- Automatically hide the reminder after successful role-specific probes. Recheck on role changes, project changes, user request, and periodic refresh.
- Keep provider tokens in SecretStorage and prevent unsupported remote write actions from claiming success.

## Validation

- Added `test/v064-role-connection-access.test.js` for required capability policy, Developer-only write requirement and UI paths.
- GitHub pull-request CI must pass before publishing or merging. The VSIX is generated by the main-branch workflow after verified merge.
